# PLAN.md — Build Sequence

1. **Contracts** — RepoGraph, GraphDelta, AgentTask, DocUnit, VisualSpec, FAQEntry, ThemePreset, SiteManifest.
2. **Ingestion** — immutable repository snapshot and language/file inventory.
3. **Static graph** — symbols/imports/dependencies/evidence.
4. **Graph intelligence** — ranking, clustering, hotspots and query layer.
5. **First Atlas** — architecture + pages + Mermaid + provenance.
6. **Machine Atlas** — raw Markdown, graph/index JSON, llms, sitemap, FAQ.
7. **Multi-agent factory** — bounded specialist stages with verifier/auditor gates.
8. **Themes/templates** — safe modular identity and repo-specific presentation.
9. **Incremental refresh** — GraphDelta-driven invalidation.
10. **Rich visual suite** — add renderers only when they improve developer comprehension.
