# BITwiki Foundry

**Foundry maps repositories into usable knowledge.**

Foundry is the repository intelligence factory. It analyzes a Git repository into a canonical code graph, coordinates bounded specialist agents, and publishes the resulting documentation and machine artifacts to **[BITwiki Atlas](https://github.com/bitwikiorg/atlas)**.

```text
Foundry
  ↓ analyzes
repository
  ↓ publishes
Atlas
```

Atlas contains source-linked documentation, graphs, ratings, provenance, and machine-readable outputs. GitHub is the durable output layer; Foundry remains the control plane.

## Core rule

> Analyze once into a canonical graph. Generate human and machine views from the same evidence.

## Project state

Planning, implementation state, and operational work remain in this repository. Generated repository knowledge belongs in `bitwikiorg/atlas`.
